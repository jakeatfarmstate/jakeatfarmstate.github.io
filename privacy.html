Privacy Policy

This policy describes the current personal-use Bausi Shorts desktop workflow operated by the owner of this site, jakeatfarmstate, and this informational website.

Google authorization and data access

Bausi uses Google OAuth to request https://www.googleapis.com/auth/youtube.upload. This permission is used to upload operator-approved videos to the authorized YouTube channel and submit their titles, descriptions, audience declaration, and scheduled publishing times. Bausi receives an upload response including the YouTube video ID. The current workflow does not request Gmail, Drive, contacts, or YouTube Analytics access.

Google handles sign-in and consent. Bausi does not request, receive, or store the operator’s Google password.

Local storage and use

The desktop application stores OAuth access and refresh tokens in youtube_token.json on the operator’s computer. OAuth application credentials are stored separately in client_secret.json. Local project storage contains source footage, rendered videos, transcripts, chat replay, emote assets, draft decisions, video IDs, and scheduled times. Transcripts may still be produced locally for clip selection even when visible subtitles are disabled.

These records support editing, review, duplicate detection, scheduling, and upload recovery. Google authorization data is used only to provide the authorized upload workflow. Google user data is not sold, used for advertising, or used to train or improve AI or machine-learning models.

Bausi Shorts’ use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements.

Transfers and third-party services

Approved video files and their metadata are sent to YouTube. Tokens are used in requests to Google’s authorization and API services. Public Twitch clip metadata, chat replay, and emote assets may be retrieved from Twitch and supported emote providers; public chat usernames and messages may appear in the resulting video. The transcription model may be downloaded from Hugging Face; the current workflow performs transcription locally and does not send audio to a hosted transcription service.

This website does not accept tokens or uploads and does not embed third-party tracking scripts. GitHub Pages hosts the website and may process visitor information such as IP addresses under GitHub’s privacy statement. Google and YouTube process data under the Google Privacy Policy; Twitch and other providers process data under their own policies. OAuth tokens are not sent to GitHub, Twitch, emote providers, or Hugging Face by this workflow.

Retention, deletion, and revocation

Local workflow records remain until the operator deletes them. To disconnect, stop the worker and remove the app’s access in Google Account connections. Delete the local youtube_token.json file to remove the stored authorization. To remove local clips and workflow records, stop the application and delete its state folder; this also removes the queue and duplicate history. Delete any copies or backups separately.

Disconnecting or deleting local files does not delete videos already uploaded or cancel their YouTube schedules. Manage those videos in YouTube Studio. If local records are deleted, review existing Studio uploads before recreating the queue to avoid duplicates.

Security and contact

Requests to Google’s authorization and API services use HTTPS. The temporary sign-in callback uses a local loopback address on the operator’s computer. The current desktop application stores the token file as local JSON and does not itself encrypt that file at rest. Keep credentials and token files private and protect the computer and backups with appropriate access controls. Credentials are not included in this public website. For privacy questions or deletion assistance, contact greengrabber330@gmail.com. Changes to the workflow’s data practices will be reflected in an updated policy.
