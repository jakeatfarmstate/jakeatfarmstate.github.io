Bausi Shorts is a personal Windows desktop tool that prepares vertical fan highlights and uploads approved videos to the operator’s YouTube channel.

What the tool does

  1. Finds recent community-created Twitch clips and downloads selected source footage.
  2. Prepares vertical gameplay and facecam videos, with available Twitch chat replay and supported emotes.
  3. Shows drafts on a local review page so the operator can check the edit and approve or reject it.
  4. Uploads approved videos through the YouTube Data API and assigns future publishing times.

Why Google authorization is requested

The desktop tool requests the youtube.upload permission to upload approved videos and set their titles, descriptions, and publishing schedules. Authorization occurs on Google’s sign-in page. This website does not sign users in or accept credentials.

Designed for personal use.

The workflow runs on the operator’s own computer. This public website provides information and policies; it does not run the editor, collect OAuth tokens, or provide a hosted upload service.
